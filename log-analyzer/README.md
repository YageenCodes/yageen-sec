# Log Analyzer / Failed Login Detector

## Overview

This project is a beginner cybersecurity tool built with Python. The program analyzes a log file and detects failed login attempts that may indicate suspicious activity or a possible brute-force attack.

## Features

* Reads a log file
* Detects failed login attempts
* Counts suspicious login activity
* Flags suspicious behavior
* Displays an alert when failed logins exceed a threshold

## Technologies Used

* Python
* Text File Analysis
* Command Prompt

## Test Results

The analyzer was tested using a sample log file containing login activity.

### Results

* Total failed login attempts detected: `7`
* Suspicious login activity alert triggered

### Example Detection

The tool detected repeated failed login attempts for users such as:

* `admin`
* `root`
