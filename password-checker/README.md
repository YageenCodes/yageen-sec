# Password Strength Checker

## Overview

This project is a beginner cybersecurity tool built with Python. The program analyzes a password and determines whether it is weak, medium, or strong based on common password security practices.

## Features

* Checks password length
* Detects uppercase letters
* Detects lowercase letters
* Detects numbers
* Detects special symbols
* Rates password strength as:

  * Weak
  * Medium
  * Strong

## Technologies Used

* Python
* String Library
* Command Prompt
