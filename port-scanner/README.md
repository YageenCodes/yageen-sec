# Python Port Scanner

## Overview

This project is a beginner cybersecurity tool built with Python. The scanner checks a target IP address for open TCP ports and reports any discovered services.

## Features

* Scans ports 1–1000
* Detects open TCP ports
* Uses Python socket programming
* Displays scan progress in real time
* Tested safely on localhost (`127.0.0.1`)

## Technologies Used

* Python
* Socket Library
* Command Prompt

## Test Results

During testing on localhost (`127.0.0.1`), the scanner identified open ports including:

* Port 135
* Port 445
